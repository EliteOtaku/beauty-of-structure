技术要点

没有用任何动画软件。每一帧由 draw(t) 纯函数画出，随机数取自固定种子， 因此同一时刻的画面可重放、可并行、可只重渲染某一场；4 个 headless Chromium 并行渲染， 帧经 WebSocket 直通 ffmpeg，6300 帧 1.9 分钟出片。配乐由 numpy/scipy 合成 （和声垫 / 钟 / Karplus-Strong 拨弦，无采样素材），旁白 8 句中文由 Windows SAPI 合成并与音乐做侧链闪避。 详见 仓库 README。

有解的东西可以被算出来，有结构的东西才能被理解。
